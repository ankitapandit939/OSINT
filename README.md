
# OSINT for Beginners

A beginner-friendly learning repository covering Open-Source Intelligence and reconnaissance fundamentals.

## About This Repository

This repository documents my journey of learning OSINT. It explains important concepts, reconnaissance tools, practical workflows, potential security risks, and defensive measures in simple language.

## What You Will Learn

- What OSINT means
- What reconnaissance means
- Types of reconnaissance: passive, active, and web reconnaissance
- Tools associated with each reconnaissance type
- How reconnaissance tools are used in authorized environments
- How collected information can create security risks
- Defensive measures for reducing information exposure

## Tools Covered

### Passive Reconnaissance

- theHarvester
- Maltego
- Recon-ng

### Active Reconnaissance

- Nmap
- Masscan
- hping3

### Web Reconnaissance

- DIRB
- Gobuster
- Nikto
- WhatWeb
- Wappalyzer

> **Note:** The classification of a tool may depend on how it is used. Some tools can perform both passive and active reconnaissance.
